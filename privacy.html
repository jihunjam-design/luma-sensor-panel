개인정보처리방침

Luma Sensor Panel(이하 "앱")은 사용자가 직접 승인한 경우에만 Google 계정 데이터에 접근합니다.

접근하는 데이터

  • Google 캘린더: 캘린더 목록과 일정(제목, 시간, 장소). 사용자가 앱에서 요청한 경우 일정을 만들거나 삭제합니다.
  • Google Tasks: 할 일 목록과 할 일 항목.

사용 목적

가져온 데이터는 사용자의 PC 화면에 일정과 할 일을 표시하는 데에만 사용합니다.

저장과 공유

  • 로그인 정보는 사용자의 PC에 Windows 사용자 계정으로 암호화해 저장하며, 외부 서버로 전송하지 않습니다.
  • Google 데이터를 개발자나 제3자의 서버로 보내거나, 판매·공유하거나, 광고에 사용하지 않습니다.
  • 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

삭제

앱 설정의 "이 PC 연결 해제"로 저장된 로그인 정보를 삭제할 수 있고, Google 계정 연결 관리에서 앱 권한을 철회할 수 있습니다.
